# Telemetry

Peek does not collect or send telemetry. The CLI, helper, macOS app, website and backend send no usage analytics or diagnostic events to Space Station or another telemetry service.

Telemetry collectors, event queues and relays have been removed. Old telemetry settings are ignored and cannot turn collection back on. The former website and macOS app telemetry switches are no longer present.

Normal features still make the requests they need: account sign-in, speech, messages, drawings and reports explicitly submitted by the user. Local diagnostic logs remain on the device. See [Privacy](privacy.md) for these data flows.
