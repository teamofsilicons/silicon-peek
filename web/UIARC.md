# Silicon UI component provenance

Peek uses the Silicon UI foundation and button styles from https://ui.teamofsilicons.com. The foundation and CSS module are copied from the public registry. A small SolidJS adapter retains native button semantics, loading state, focus rings and reduced motion without adding a second frontend runtime.

The existing specialized bubble controls retain their Arc MIT attribution in `licenses/uiarc-MIT.txt`. Silicon UI is the MIT-licensed continuation of Arc by Team of Silicons. Native macOS controls continue to use SwiftUI.
